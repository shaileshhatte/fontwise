# CLAUDE.md

Guidance for AI coding agents (Claude Code, Copilot, …) working in this repository. Read it before editing.

## What this is

**Fontwise**: a Manifest V3 browser extension for Chromium (121+) and Firefox (140+, Android 142+) that makes web pages easier to read. Features:
- **Fonts:** four built-in OFL fonts and a curated picker of installed readable fonts, including CJK, Arabic, Devanagari and Hebrew.
- **Reading controls:** size, spacing, weight and style, line length, margins, alignment, colour themes with a contrast check, and a reading ruler.
- **Presets:** built-in and user presets.
- **Scopes:** tab, site or everywhere, plus excluded sites.
- **Focus mode**, built on Mozilla Readability.
- **Automatic dark colours.**
- **Keyboard shortcuts.**
- **Settings page:** sync, backup.

Plain HTML/CSS/JS, **no build step, no runtime dependencies, no framework**. MIT licensed.

## Layout

```

  _locales/en/messages.json every user-visible string

    settings.js             limits, defaults, themes, presets, sanitize*, resolve, siteKey, isNight, contrast
    css.js                  buildCss, fontFaceCss, readerCss
    catalog.js              FONT_CATALOG, SYSTEM_FONTS, CATALOG_VERSION, detectInstalledFonts, availableFonts
    bundled-fonts.js        GENERATED by tools/vendor-assets.mjs

    i18n.js                 t, localize, describeSettings, themeLabel, commandLabel
    ui.js                   roving (arrow keys), setTabStop, announce
    tokens.css, page.css    design tokens (light/dark/forced colours/reduced motion); full-page layout
  scripts/content.js        style element, reading ruler, Focus mode, toast, automatic dark
  scripts/background.js     FW_GET, badge, live broadcast, commands, install/update
  popup/  options/  welcome/
  fonts/  vendor/readability/   GENERATED by `npm run vendor` — never edit by hand
  icons/                    16/32/48/128 px PNGs
tests/unit/                 node:test + node:vm (*.test.js)
tests/e2e/                  Playwright, Chromium with the extension (*.spec.js)
```

## Commands

```sh
npm install            # once; then `npx playwright install chromium` for e2e
npm run lint           # expect 0 errors; known warnings: BACKGROUND_SERVICE_WORKER_IGNORED, 2× UNSAFE_VAR_ASSIGNMENT in vendor/readability
npm test               # unit tests
npm run test:e2e       # Playwright end-to-end tests
npm run vendor         # refresh extension/fonts, extension/vendor, shared/bundled-fonts.js
npm run screenshots    # regenerate assets/store/screenshots/ and the marquee tile after UI changes (needs Playwright Chromium)
npm run video          # regenerate assets/store/video/ (also needs ffmpeg with libx264, or FFMPEG=/path)
npm run build          # dist/fontwise-<version>.zip
npm run start:firefox  # or start:chrome; live-reloading temporary profile
```

If `npm` fails with cache permission errors on this machine, prefix commands with `npm_config_cache=/tmp/fontwise-npm-cache`.

## Golden rules

1. **One source for every browser.** Never fork code per browser. Use `const ext = globalThis.browser ?? globalThis.chrome;` and promise-returning APIs; feature-test optional APIs. In `runtime.onMessage` use `sendResponse` + `return true`.
2. **Shared code is re-injectable.** Files in `shared/` and `content.js` may run twice in one page: wrap them in an IIFE, attach to `globalThis.Fontwise`, no top-level `const`/`let`/`class`.
3. **No remote resources.** No web fonts, CDNs, `@import`, analytics or network requests. Built-in fonts ship in `extension/fonts/` under `Fontwise <Name>` family names (never the real name, or detection breaks).
4. **Validate through `FW.sanitizeSettings()`** before anything reaches CSS, storage or the UI from an untrusted source (storage, messages, imports, sync). Keep the clamps in `LIMITS`, the `#rrggbb` check, the font-stack regex `/^[\w\s"',.-]+$/` and the enumeration allow-lists.
5. **Page content is hostile.** Focus mode rebuilds the article with `createElement` and allowlists (`rebuild()` in content.js). Never move or adopt parsed nodes into the page, never use `innerHTML` with dynamic data, no `eval`/`new Function`, no inline handlers.
6. **Accessibility is required:**
   - every control has a label;
   - option groups use roving tab stops (`FW.roving`);
   - state is exposed with `aria-pressed`, `aria-checked` or `aria-selected`;
   - sliders set `aria-valuetext`;
   - changes are announced with `FW.announce`;
   - forced colours and `prefers-reduced-motion` are honoured;
   - decorative SVGs are `aria-hidden`.
7. **All UI text goes through i18n** (`data-i18n*` attributes or `FW.t`). Add the key to `_locales/en/messages.json`; the integrity test fails on missing keys.
8. **Permissions stay minimal**: `storage`, `scripting`, host access to `http://*/*` and `https://*/*`. Any addition needs explicit approval plus README, PRIVACY and PUBLISHING updates.
9. **Privacy of scopes:** site settings live only in `storage.local` and are never written from incognito tabs (`store.write` enforces this). Only portable keys (`fw_global`, `fw_prefs`, `fw_excluded`, `fw_preset_*`) may go to `storage.sync`.
10. **Bump `CATALOG_VERSION`** in `shared/catalog.js` whenever `FONT_CATALOG` changes.
11. Internal ids (`fw_*` keys, `FW_*` messages, `__fontwise_style__`, `fontwise-*` elements) are stored or observable; renaming them after a release needs a migration.

## Contracts

| Message     | Direction                  | Payload                  | Reply                                                   |
| ----------- | -------------------------- | ------------------------ | ------------------------------------------------------- |
| `FW_GET`    | content → background       | —                        | `{ settings, autoDark }` or `null`                      |
| `FW_PING`   | popup/background → content | —                        | `true`                                                  |
| `FW_APPLY`  | popup/background → content | `{ settings, autoDark }` | `true`                                                  |
| `FW_READER` | popup/background → content | `{ notify }`             | `{ ok, open }` or `{ ok: false, reason: 'no-article' }` |

| Storage key      | Area                                         | Shape                                              |
| ---------------- | -------------------------------------------- | -------------------------------------------------- |
| `fw_tab_{tabId}` | `session`                                    | settings (`FW.DEFAULT_SETTINGS` shape)             |
| `fw_site_{host}` | `local` only                                 | settings                                           |
| `fw_global`      | portable (`sync` if `fw_sync`, else `local`) | settings                                           |
| `fw_prefs`       | portable                                     | `{ defaultScope, autoDark: { mode, start, end } }` |
| `fw_excluded`    | portable                                     | `string[]` host names                              |
| `fw_preset_{id}` | portable                                     | `{ id, name, settings, createdAt }`                |
| `fw_sync`        | `local`                                      | `boolean`                                          |
| `fw_font_cache`  | `local`                                      | `{ catalogVersion, installedIds[], scannedAt }`    |

Effective settings = tab ?? site ?? (excluded ? null : global). `FW.CONTENT_SCRIPTS` must equal `content_scripts[0].js` in the manifest. The background's `importScripts` list must equal `background.scripts` minus `background.js`. Tests check both.

## Adding things

- **Numeric setting:** `LIMITS` + `DEFAULT_SETTINGS` (settings.js) → `buildCss()` (css.js) → `RANGE_FORMAT`, `RANGE_IDLE` and a `.row[data-row]` with `input.range[data-key]` (popup) → messages → unit test.
- **Segmented setting:** `CHOICES` (settings.js) → `buildCss()` → `.segmented[data-key]` (add `data-type="number"` for numbers).
- **Installed font:** an entry in `FONT_CATALOG`; use `detect: [...]` for platform-specific names and `script:` for non-Latin. Bump `CATALOG_VERSION` and update the counts in README, ARCHITECTURE and CHANGELOG.
- **Built-in font:** the `@fontsource` devDependency → `FONTS` in `tools/vendor-assets.mjs` → `npm run vendor` → a catalogue entry with `bundled: 'Fontwise <Name>'` → THIRD_PARTY_NOTICES.md.
- **Theme or preset:** `THEMES` / `PRESETS` in settings.js, the matching button in popup.html, and `.swatch[data-theme]` colours in popup.css.
- **Shortcut:** `commands` in the manifest (Chrome allows 4 suggested keys) → `COMMANDS` in background.js → `COMMAND_KEYS` in i18n.js → messages.

## Style

- ES2022, `'use strict'`, `.editorconfig` formatting (2 spaces; HTML 4).
- Comments only for what the code cannot say itself, one short line.
- Use the tokens in `shared/tokens.css` (indigo accent `#6366f1`; dark default, light via `prefers-color-scheme`). Animate only `opacity`, `translate`, `scale` and colour. The popup is 360 × 600 px on desktop and full screen on touch devices.
- User-visible changes: update `CHANGELOG.md` (*Unreleased*) and keep the README tables (ranges, presets, shortcuts, catalogue counts) in sync with the code.
- Release: bump only `extension/manifest.json` `version`; the release workflow checks that the git tag matches it.
